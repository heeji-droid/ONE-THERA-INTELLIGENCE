## 입장 조건 — 여기서 지어내지 않는다

기회를 쓰기 전에 확인한다:

```
G1  독립 출처 ≥ 3
G2  서로 다른 Tier ≥ 2
G3  Tier 1–2 근거 ≥ 1건    (없으면 → 유행)
G4  Tier 4 소비자 목소리 ≥ 1건 (없으면 → 논문)
G5  30단계 해석 존재         (왜인지 모르면 카피를 쓸 수 없다)
G6  40단계 경로 ≠ Fade
```

**게이트를 통과하지 못한 아이디어는 쓰지 않는다.**
대신 "무엇을 더 수집하면 통과하는가"를 쓴다. 그것이 다음 라운드의 지시가 된다.

> 브레인스토밍은 언제나 가능하다. 이 시스템의 가치는 **하지 않을 수 있다는 것**이다.

## 기회의 형태 — 5종

`01_TAXONOMY.md`의 08 노드에 대응한다. 하나의 클러스터에서 여러 형태가 나올 수 있다.

| 형태 | 답해야 하는 질문 |
|---|---|
| `08.NEED` | 아직 아무도 **이름 붙이지 않은 요구**는 무엇인가 |
| `08.PRODUCT` | 그것을 **무엇으로** 해결하는가 (성분·제형·루틴 위치) |
| `08.BRAND` | 우리는 어떤 **단어를 소유**하는가 |
| `08.CAMPAIGN` | 3초 안에 **무엇을 말하는가** |
| `08.WHITE` | 01–07 교차에서 비어 있는 좌표는 어디인가 |

**`08.NEED`부터 쓴다.** 이름 붙이기가 먼저다.
이름 없는 요구는 소비자가 검색하지 못하고, 검색하지 못하면 팔리지 않는다.

---

## 언어 레이어 (06) — 반드시 포함

기회는 **소비자의 언어로** 쓰여야 한다. 마케터의 언어로 쓰인 기회는 실행 단계에서 죽는다.

- 반드시 저장소의 **`verbatim` 필드에서 실제 문장을 인용**한다. 지어낸 소비자 문장 금지
- 카피는 `desired_outcome`에서 나온다. "효과"가 아니라 그 사람이 **도달하려는 상태**를 말한다
- 소비자 어휘를 그대로 쓴다 (`06.WORDS`)
- 작용기전은 **비유**로 옮긴다 (`06.META`)
- 훅은 **정보 격차**로 만든다 (`06.CURIO`) — 설명하지 말고 멈추게 한다
- 증거의 언어를 붙인다 (`06.PERSUADE`) — 단, `03.CLAIM`의 규제 한계를 넘지 않는다

## 마지막 규칙

1. **`08.*` 태그로 새 Atomic Insight를 만들지 않는다.** 기회는 파생 산출물이다
2. 기회는 **`docs/opportunities/`** 에 날짜와 함께 보관한다. 폐기된 기회도 지우지 않는다 —
   왜 틀렸는지가 다음 판단을 정확하게 만든다
3. **가장 싼 검증 방법**이 없는 기회는 미완성이다. 확신은 실험을 대체하지 않는다
4. 좋은 기회 3개가 평범한 기회 10개보다 낫다. **점수 낮은 것은 `watch`로 보내고 끝낸다**
