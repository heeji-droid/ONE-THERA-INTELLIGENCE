# 40 — PREDICT · 12–36개월 전개

> 앞에 `00_MASTER.md`를 붙인다.
> 입력: 30단계의 해석
> 출력: 시나리오 + 반증 조건 (마크다운)

예측의 목적은 **맞히는 것이 아니라 지금 무엇을 할지 결정하는 것**이다.
따라서 모든 예측에는 **틀렸음을 알 수 있는 조건**이 붙는다.

---

## TASK

### 1. 전개 경로 (Trajectory)

각 신호에 대해 셋 중 하나로 판정하고 근거를 쓴다.

| 경로 | 정의 | 판단 근거 |
|---|---|---|
| **Fade** | 12개월 내 소멸 | 촉발 요인이 순환적 · 플랫폼 의존 · 대체재 등장 |
| **Absorb** | 기본값이 되어 차별점 소멸 | 대형 브랜드가 이미 채택 중 · 진입장벽 낮음 |
| **Structural** | 되돌아가지 않는 이동 | 규제/인구/기술 기반 · 07.STRUCT 근거 존재 |

**Absorb 판정이 가장 중요하다.** 사라지지 않지만 **더 이상 기회가 아닌** 상태이며,
대부분의 브랜드가 여기서 늦게 진입해 실패한다.

### 2. 타이밍

```
NOW      (0–6개월)   이미 늦었을 수 있음 — 차별화 각도 필요
NEXT     (6–18개월)  ★ 실행 최적 구간
LATER    (18–36개월) 관찰 + 역량 준비
WATCH    (36개월+)   기록만
```

각 클러스터를 하나의 구간에 배치하고, **왜 그 구간인지**를 쓴다.
"곧" "빠르게" 같은 말은 쓰지 않는다.

### 3. 2차 효과

1차 효과는 모두가 예측한다. **2차·3차를 쓴다.**

```
1차: 소비자가 성분 근거를 요구한다
2차: 브랜드가 임상 데이터를 마케팅한다 → 임상 주장의 인플레이션
3차: 소비자가 임상 주장 자체를 불신한다 → "누가 검증하는가"가 새 전장이 된다
        ↑ 여기가 약사 자산의 진짜 기회 지점
```

2차 효과에서 나온 기회가 1차보다 거의 항상 크다.

### 4. 반증 조건 (필수 · N8)

> **"무엇이 관찰되면 이 예측을 폐기하는가?"**

관측 가능하고 날짜가 붙은 조건으로 쓴다.

```
✅ "2027-03까지 Sephora 상위 20개 신제품 중 이 각도를 쓴 제품이 3개 이상이면 → Absorb으로 재분류"
❌ "관심이 줄어들면 폐기"
```

### 5. 재점검 시점

이 예측을 언제 다시 볼 것인지 날짜를 정한다. 날짜가 없는 예측은 검증되지 않는다.
