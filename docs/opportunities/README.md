# docs/opportunities

`prompts/50_OPPORTUNITY.md`가 생산한 기회 카드 보관소.

```
YYYY-MM-{slug}.md
```

## 규칙

1. **폐기된 기회를 지우지 않는다.** 상단에 `STATUS: dropped` 와 폐기 사유·날짜를 추가한다.
   왜 틀렸는지의 기록이 다음 판단을 정확하게 만든다.
2. 모든 카드는 `근거 인사이트` 목록(`AI-id`)을 갖는다. 근거 없는 카드는 카드가 아니다.
3. `폐기 조건`의 날짜가 지나면 그날 다시 연다. 재점검하지 않은 카드는 자산이 아니라 부채다.

## STATUS

| 값 | 의미 |
|---|---|
| `watch` | 게이트 미통과 또는 자산 부적합. 관찰만 |
| `active` | 검증 실험 진행 중 |
| `committed` | 개발 착수 |
| `dropped` | 폐기 — 사유와 날짜 필수 |
